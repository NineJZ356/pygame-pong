# Pong Game

A simple 2D Pong game built with Pygame Community Edition.

Features:
- One-player mode against a CPU-controlled paddle
- Local two-player mode using one keyboard
- Score tracking and quick reset between rounds

## Requirements
- Python 3.10+
- pygame-ce

## Installation

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
python -m src.main
```

## Controls

Single-player:
- Left paddle: W / S
- CPU: automatic right paddle

Two-player:
- Left paddle: W / S
- Right paddle: Up / Down

Menu:
- Press 1 for one-player mode
- Press 2 for two-player mode
- Press Esc to quit or return to menu
